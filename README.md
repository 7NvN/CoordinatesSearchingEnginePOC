# Shopbook / दुकान बही

A counter book for one shop: bills, stock, udhaar, expenses, and a receipt you can print or send. It stays on the shop computer. There is no monthly fee.

Phone and computer share the same book when they are on the shop Wi-Fi.

## Start the day

1. Double-click `start-shop.bat`.
2. Leave the black window open.
3. The browser opens the book. The first time, type the shop name.
4. On the shop phone, connect to the same Wi-Fi and open the address shown in that window (it looks like `http://192.168.x.x:8080/`).
5. If Windows asks, allow it on private networks.

Do not forward this address to the internet.

## Receipts

After a bill, use **Print / PDF**. In the print box choose **Save as PDF** or **Microsoft Print to PDF**, then send that file on WhatsApp or email. **WhatsApp** also sends the bill as text. **Email** opens a mail with the bill written out.

## Language

Use **EN / हिं** at the top. Money is always in rupees.

## Backup

In Settings, download a backup once a week. The computer also keeps the latest copies in `data/backups`.

## Sample items

Mattresses, pillows, ply, foamfix, nails, wooden boards, sunmica, fevicol, and blankets can be loaded as samples. Their rates are examples. Change them before you sell. Add or delete any item later. Barcode scanning and staff logins are not in this version; item codes are saved for a later scanner.
